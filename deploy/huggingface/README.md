# PaperTrader 3D

A Java paper trading simulator (stocks, crypto, ETFs) with real live prices,
running in your browser. Log in with **demo / demo** or create an account.

This is a shared demo: everyone who opens the Space sees the same screen, and
accounts reset when the Space restarts. For your own private copy, download the
desktop app from the project's download page.

Source code: https://github.com/aarav471471/finance-paper-trading-simulator
